FittingUtils

Parameter fitting with priors. fit_model fits model(input, θ) to data by least squares (LevenbergMarquardtFit, with using NonlinearSolve) or by MCMC (TuringFit, with using Turing). Both return a FitResult: one distribution per parameter, the full covariance, convergence diagnostics, and the StatsAPI accessors (coef, stderror, vcov, confint, predict, loglikelihood, aic, bic).

Priors are a ComponentVector of distributions in the layout of θ. Every method works in units of the prior widths (ParameterScaling). Data with per-point uncertainty is a vector of Normals. Plain numbers fit with an estimated noise level, for least squares only.

Several datasets with shared and private parameters are fitted with fit_model([(model1, x1, data1), (model2, x2, data2)], priors, method). fit_series fits a series of datasets whose parameters drift along a coordinate, optionally GP-filtered with GaussianDrift (using AbstractGPs).

Example

using FittingUtils, NonlinearSolve, ComponentArrays, Distributions

model(x, θ) = @. θ.ampl * exp(-x^2 / (2 * θ.width^2)) + θ.bg
x = range(-3, 3, length = 200)
y = model(x, (ampl = 2.0, width = 0.7, bg = 0.3)) .+ 0.05 .* randn(length(x))
data = Normal.(y, 0.05)

priors = ComponentVector(ampl = Normal(1, 2), width = Normal(1, 0.5), bg = Normal(0, 1))
fr = fit_model(model, x, data, priors, LevenbergMarquardtFit())

coef(fr), stderror(fr), reduced_chisq(fr)
confint(fr).lower.width, confint(fr).upper.width
band = predict(fr; uncertainty = true)

using Turing
mc = fit_model(model, x, data, priors, TuringFit(); init = fr, progress = false)

FittingUtils.DriftModel — Type
DriftModel

How tracked parameters evolve along the series coordinate. A drift model implements three functions:

  • init_drift(drift, keys, priors) -> state
  • drift_predict(state, key, t) -> (μ, σ): same shape as the component
  • drift_update!(state, key, t, μ, σ)

FittingUtils.FitResult — Type
FitResult(model, input, marginals, residuals, weights)

Result of a fit.

  • marginals: one distribution per parameter (a Normal from the Laplace approximation for LevenbergMarquardtFit, a posterior marginal for TuringFit). Components may themselves be vectors of distributions.
  • residuals: data residuals only, without prior terms, so nobs/dof_residual/rss count observations.
  • weights: per-point weights 1 / σᵢ when the data carried its own uncertainty, nothing when it did not.
  • vcov: full parameter covariance in physical units, ordered like the flattened parameter vector (getdata(coef(fr))). nothing when the fitting method did not provide one.
  • diagnostics: NamedTuple of convergence diagnostics, nothing when the method provides none. Always carries converged::Bool; LevenbergMarquardtFit adds retcode, covariance_ok and at_bound (labels of the parameters at a Uniform bound), TuringFit adds rhat.

FittingUtils.GaussianDrift — Type
GaussianDrift(; lengthscale, kernel = nothing, noise_inflation = 1.0, window = 64)

GP drift: each tracked scalar gets GP(ConstMean(μ₀), σ₀²·k), mean and variance taken from its prior. Default kernel ½·SE(ℓ) + ½·SE(10ℓ); kernel accepts any unit-variance KernelFunctions kernel instead. Only components with Normal priors can be tracked.

Each converged frame conditions the GP on what its data alone say: the frame's prior, which is the GP's own prediction, is divided out of its posterior first (per scalar, as Gaussians). The observation noise is (noise_inflation·σ)²; noise_inflation > 1 is a safety margin against model error. Only the last window observations per scalar are kept, so the cost stays O(window³).

Requires using AbstractGPs.

FittingUtils.LevenbergMarquardtFit — Type
LevenbergMarquardtFit()

Least-squares fitting with NonlinearSolve.jl's Levenberg-Marquardt solver: the result's marginals are Normals from the Laplace approximation at the optimum. Needs using NonlinearSolve. See fit_model for its keywords.

FittingUtils.NotTracked — Type
Tracked(keys...) / NotTracked(keys...)

Selectors for which components of the priors drift along the series. With no selector, every trackable component drifts. Tracked lists exactly the drifting components; NotTracked lists the static ones and everything else drifts. Components pinned by zero-width priors, or whose priors are not distributions, are never tracked.

A drift model other than StaticDrift replaces the prior of a tracked component by a Normal, so it tracks only components whose priors are Normal: others (a Uniform box) keep their prior in every frame, and naming one in Tracked is an error.

source
FittingUtils.ParameterScaling — Type
ParameterScaling(priors; scale = nothing)

Affine map between physical parameters and the scaled parameters the fitting methods work with: z = (θ - μ) / σ, with μ the prior means and σ the prior widths (std). A zero-width prior (Dirac) pins its parameter: it is not free, and every scaled value maps back to the prior mean.

scale overrides the widths of some components, e.g. scale = (; T = 10.0) or scale = (; background = fill(1e-3, 7)), for priors that are deliberately wide. Widths must be positive, and a pinned parameter cannot be scaled.

Fields: μ, σ (flat vectors in the order of the priors), free (a BitVector, false where pinned), axes (the component layout).

FittingUtils.SeriesFitResult — Type
SeriesFitResult

Result of fit_series: the coordinate vector ts, one FitResult per frame in frames, and the final drift state. A frame that failed outright holds its prior as the marginals, with converged == false. Index with sres[k]; summarise with trajectory, coef, stderror, converged.

FittingUtils.StaticDrift — Type
StaticDrift()

No drift: every frame keeps the initial prior and results never feed back, i.e. sequential fitting with warm starts only. The default, and needs no extension. Use GaussianDrift for GP filtering.

FittingUtils.fit_model — Function
fit_model(model, input, data, priors, method; kwargs...)

Fit model(input, θ) to data. priors is a ComponentVector of distributions with the layout of the parameters θ; their means are the start values. data is a vector of numbers, or of distributions carrying the per-point uncertainty. Returns a FitResult.

Every method solves for the parameters in units of their prior width, centred on the prior mean (ParameterScaling). scale = (; T = 10.0) overrides the width of a component, for priors that are deliberately wide. init sets a start point other than the prior means: a ComponentVector in the layout of priors, or a previous FitResult.

LevenbergMarquardtFit()

Needs using NonlinearSolve. Priors may be Normal, Uniform (a box), or Dirac (pinned). A plain number is a free parameter without a prior, starting at that value. Normal priors take effect only when data carries per-point uncertainty; without it they are ignored, with a warning. Bounds and pins always hold: the model is only ever evaluated inside the box. A parameter that ends at a bound is warned about and listed in diagnostics.at_bound. The reported covariance is that of the problem without the box: for a parameter at a bound it says how well the data determine it there, ignoring the bound, so its interval can reach outside the box. The model output must have the length of data. Keywords:

  • maxiters = 1000, abstol = 1e-6, reltol = 1e-3, termination_condition
  • damping_initial = 1.0, damping_increase_factor = 2.0, damping_decrease_factor = 3.0, disable_geodesic = Val(true), autodiff = AutoForwardDiff(), or a whole alg (e.g. TrustRegion())
  • fuse: one ForwardDiff pass per residual call yields value and Jacobian; on by default with AutoForwardDiff and no geodesic acceleration
  • approximate_uncertainties = false: true uses the Gauss-Newton JᵀJ instead of the exact Hessian for the covariance
  • show_trace = Val(false), trace_level

TuringFit()

Needs using Turing, and data with per-point uncertainty. Priors must be Normal, Uniform, or Dirac. Keywords: sampler = NUTS(), num_samples = 1000, num_chains = 1, progress = true. Chains run in parallel on deepcopys of the model when Julia has threads. A model with mutable state must therefore be passed as the object itself, not as a closure over a global: deepcopy does not copy what a closure references.

FittingUtils.fit_model — Method
fit_model(datasets, params, method; kwargs...)

Fit several datasets simultaneously. datasets is a vector of (model, input, data) tuples; every model receives the full global params vector and reads what it needs, so a shared parameter is one read by several models and a private parameter is a dataset-indexed component (θ.ampl[i], or a matrix column θ.bg[:, i] per dataset).

Every keyword of the chosen method applies. Per-dataset views of the result: residuals/rss/nobs/predict with dataset = i.

source
FittingUtils.fit_series — Method
fit_series(model, ts, inputs, data_per_frame, priors, method;
           drift, track = nothing, per_frame_inputs = nothing, kwargs...)

Fit an ordered series of datasets whose parameters drift smoothly along the coordinate ts (time, position). A forward Bayesian filter: frames are fit in order, each frame's prior for the tracked components is the drift model's predictive at its coordinate, its start point is the previous frame's estimate, and each converged result conditions the drift for the frames after it, on the information of its own data only (the frame's prior is divided out).

  • inputs: one shared input, or a vector with one input per frame. A vector of arrays is read as per-frame; per_frame_inputs = true/false says which it is when that guess is wrong (a shared input that is itself a vector of arrays).
  • data_per_frame: one data vector per frame.
  • priors: initial prior; for tracked components it also sets the drift's mean and variance scale. track: see Tracked.
  • drift: a DriftModel. Default StaticDrift, i.e. fixed priors and warm-started sequential fits; GaussianDrift for GP filtering.
  • Remaining keywords go to every per-frame fit_model call.

A frame that fails or does not converge is warned about, recorded unconverged (holding its prior as the marginals if the solve threw), and skipped by the drift, which extrapolates over it. Errors that point at the code rather than the frame (MethodError, UndefVarError, a missing field, Ctrl-C) are rethrown.

FittingUtils.inverse_sigmas — Method
inverse_sigmas(data) -> Vector or nothing

Per-point weights 1 / σᵢ when data carries its own uncertainty (each element a Distribution), nothing when it does not (plain numbers). Mixed or invalid (non-positive, non-finite σ) input throws, naming the offending indices.

FittingUtils.mse — Method
mse(fr)

rss(fr) / dof_residual(fr). Its meaning depends on the data:

  • With per-point uncertainties, the residuals are divided by σᵢ and mse is the reduced χ², ≈ 1 for a good model (see reduced_chisq).
  • Without, mse is the estimated noise variance σ̂², in squared data units.
source
FittingUtils.reduced_chisq — Method
reduced_chisq(fr)

Reduced χ²: rss(fr) / dof_residual(fr) with σ-normalised residuals. Errors unless the fit had per-point uncertainties: without them the same ratio is a variance estimate, not a goodness-of-fit statistic (use mse).

source
FittingUtils.trajectory — Method
trajectory(sres, key; level = 0.95) -> (t, mean, std, lower, upper)

One component's evolution along the series, with equal-tailed level intervals from each frame's marginals (posterior quantiles for MCMC frames, Gaussian ones for LM frames).

StatsAPI.dof — Method
dof(fr)

Degrees of freedom consumed by the model (StatsAPI semantics): the fitted parameters, plus the noise scale when it had to be estimated (no per-point uncertainties). Parameters pinned by a zero-width prior are not counted. For the residual degrees of freedom use dof_residual.

source
StatsAPI.dof_residual — Method
dof_residual(fr)

Residual degrees of freedom: nobs(fr) minus the fitted parameters. Pinned parameters are not counted.

source
StatsAPI.loglikelihood — Method
loglikelihood(fr)

Gaussian log-likelihood at the fitted parameters. With known per-point σ: -χ²/2 + Σ log wᵢ - n/2 log 2π. Without, the MLE noise scale σ̂² = rss/n is plugged in and counts as one extra consumed degree of freedom in dof, and so in aic/bic.

source
StatsAPI.nobs — Method
nobs(fr; dataset = nothing)

Number of observations; for a multi-dataset fit, dataset = i restricts to one dataset. Same keyword on residuals and rss.

source
StatsAPI.predict — Function
predict(fr, input = fr.input; uncertainty = false, dataset = nothing)

Model evaluated at the fitted parameters. With uncertainty = true returns Normals whose σ is the delta-method confidence band √diag(J Σ Jᵀ) from vcov: model uncertainty only, no data noise. For a multi-dataset fit, dataset = i evaluates that dataset's model (at its own input unless input is given).

source
StatsAPI.residuals — Method
residuals(fr; dataset = nothing)

Data residuals data - model, divided by σᵢ when the data carried per-point uncertainties. Prior rows are not included.

source
StatsAPI.rss — Method
rss(fr; dataset = nothing)

Residual sum of squares. With per-point uncertainties the residuals are σ-normalised, so this is χ².

source

vcov(fr) -> Matrix

Full parameter covariance in physical units, ordered like the flattened parameter vector (getdata(coef(fr))).
